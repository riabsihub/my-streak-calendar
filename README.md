# My Streak Calendar

A free, minimal, mobile-friendly yearly streak calendar.

## Publish free with GitHub Pages
1. Sign in or create a GitHub account.
2. Create a new repository named `my-streak-calendar`. For the simplest setup, make it **Public**.
3. Upload `index.html`, `manifest.json`, `service-worker.js`, and `icon.svg` from this folder to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the published URL shown in Settings → Pages. It usually looks like `https://YOUR-USERNAME.github.io/my-streak-calendar/`.
7. Open that URL on your phone.

## Add to home screen
- **iPhone (Safari):** Share → Add to Home Screen.
- **Android (Chrome):** menu (⋮) → Add to Home screen or Install app.

## Important data note
Checkmarks are saved in the browser on the device you use. They do not automatically sync between devices, and clearing browser/site data can erase them. Use **Export backup** periodically. Importing a backup replaces the checkmarks on that device.

The website code is public if the repository is public, but your checkmarks are not uploaded to GitHub; they stay in the browser's local storage.
